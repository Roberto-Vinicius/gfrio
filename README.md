# GFRIO Refrigeração Comercial

Aplicação web institucional da **GFRIO Refrigeração Comercial**, desenvolvida em **React + TypeScript + Vite** com backend de envio de e-mails em **Node.js + Express + Nodemailer**.

## Servidor de Desenvolvimento (Front-end)

Execute `npm run dev` (ou `npm start`) para iniciar o servidor de desenvolvimento Vite. Acesse `http://localhost:4200/`.

## Servidor de E-mail (Back-end)

Execute `npm run server` (ou `node backend/server.js`) para iniciar a API de envio de formulário na porta `3001` (`http://localhost:3001/send-email`).

## Build de Produção

Execute `npm run build` para compilar o TypeScript e gerar os artefatos otimizados de produção no diretório `dist/`.
